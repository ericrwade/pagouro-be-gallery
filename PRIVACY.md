# Privacy — Pagouro BE Gallery

Pagouro BE Gallery collects nothing.

- It makes no network requests. Nothing is sent to pagouro.com, to the author, or to anyone else.
- It reads only the pictures bundled inside the plugin, or a folder you name yourself with `/pagouro_be folder`.
- It writes no files, starts no processes and changes no settings.
- It keeps a few values in memory while your Claude Code session runs (which picture is showing, the pace, whether it
  is paused) and forgets them when the session ends.
- It has no analytics, no tracking, no account and no cookies.

The plugin's whole source is one readable file, `plugins/pagouro-be-gallery/hooks/register.tsx`, in this repository.

Questions: open an issue at https://github.com/ericrwade/pagouro-be-gallery/issues.
